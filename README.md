🧭 What the Project Does
Clarity empowers citizens to track and engage with local development projects. It bridges the gap between users, contractors, and administrators through a structured project management funnel:
- User Registration – Sign up and select your locality.
- Project Selection – Browse and follow nearby development projects.
- Feedback Submission – Share reviews, upload images, and report issues.
- Contractor Updates – Contractors log progress and milestones.
- Admin Oversight – Admins manage users, verify updates, and ensure transparency.
- 
🌟 Why the Project Is Useful
- Community Engagement: Citizens become active participants in development.
- Real-Time Monitoring: Live updates from contractors and admins.
- Media-Driven Feedback: Users can upload photos/videos to validate progress.
- Scalable Architecture: Built with MongoDB, Express.js, React.js, and Node.js.
